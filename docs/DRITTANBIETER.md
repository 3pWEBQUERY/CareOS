# Daten von Drittanbietern

## Feiertage

Die gesetzlichen Feiertage je Land, Kanton und Bundesland (Dienstplan › Einstellungen › Feiertage) stammen aus dem
Paket [date-holidays](https://github.com/commenthol/date-holidays) von Christopher Hiller (commenthol). Code unter ISC,
die Feiertagsdaten unter [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). CareOS übernimmt nur Feiertage
vom Typ „public“ (gesetzlich) mit deutschen Namen; die Leitung prüft und ergänzt sie im Dienstplan.
